# 성능과 정확도

측정 환경: Windows 11, CPython 3.13.5, 2026-08-09. 시간은 5회 중앙값입니다.

## 지연 시간

| 경로 | 100자 | 1,000자 | 10,000자 |
| --- | ---: | ---: | ---: |
| G2P 통합 경로 | 0.520 ms | 4.690 ms | 54.200 ms |
| Kiwi 형태소 G2P | 1.240 ms | 11.720 ms | 126.350 ms |
| 숫자 혼합 normalizer | 1.290 ms | 10.510 ms | 108.670 ms |

첫 Kiwi 초기화는 약 1.97초입니다. 인스턴스를 재사용해야 합니다.

## 짧은 문장 대량 처리

| 입력 | 처리량 |
| --- | ---: |
| normalizer 일반 한글 | 166,007문장/초 |
| normalizer 문맥 숫자 포함 | 1,841문장/초 |

숫자 문장의 주 비용은 Kiwi 분석입니다. 내부 스레드 병렬화는 더 느렸으므로 제공하지
않습니다. 여러 코어가 필요하면 프로세스 워커를 사용합니다.

## 정확도

비봉인 AIHub dev 13,114구간([데이터 출처와 이용정책](../NOTICE)):

| 구현 | 정답 | 오독 |
| --- | ---: | ---: |
| 규칙 전용 | 8,219 (62.7%) | 561 (4.3%) |
| 현재 모델 | 8,364 (63.8%) | 406 (3.1%) |

dev는 반복 개발에 사용했으므로 독립 홀드아웃이 아닙니다. 봉인 test는 최종 릴리스
검증 전까지 사용하지 않습니다.
